# Tic-Tac-Toe

Play tic-tac-toe against the computer in your browser.

Open `src/tic-tac-toe.html` in a browser. No build step or dependencies.

- **Easy**: the computer plays random moves.
- **Medium**: the computer plays the best move most of the time.
- **Hard**: the computer uses minimax and never loses.

You can choose who moves first. The score is saved in your browser.
